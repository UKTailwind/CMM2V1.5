# Appendix M – Firmware Applicability

The same firmware runs on both generations of the Colour Maximite 2. Where an entry in Commands, Functions, Options or Predefined Read Only Variables is not available everywhere, the restriction is written as an underlined label at the start of its description. An entry with no label is available on both generations.

These are the labels, and what each means:

{widths: 35,65}
| Label | Meaning |
|---|---|
| GENERATION 2 ONLY | Available on the Generation 2 Colour Maximite 2 only (it needs its larger memory, its 24-bit colour or its extra hardware: for example the 32-bit colour depth, MODE 16 and OPTION DS3231). |
| IN THE 4-BIT COLOUR DEPTH ONLY | Available only in a 4-bit mode (MODE n,4: the PicoMite's 16 colour display). |
| IN THE 12-BIT COLOUR DEPTH ONLY | Available only in a 12-bit mode, the one with transparency. |

No other wording is used for applicability, so that a reader can find every restriction by looking for these labels.
