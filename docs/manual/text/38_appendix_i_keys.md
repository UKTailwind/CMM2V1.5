# Appendix I – Special Keyboard Keys

## Special Keyboard Keys

MMBasic generates a single unique character for the function keys and other special keys on the keyboard. These are shown in this table as hexadecimal and decimal numbers. Where a key gives a different code when the Shift key is held down, that code is shown too.

{widths: 34,22,22,22}
| Keyboard Key | Key Code (Hex) | Key Code (Decimal) | With Shift (Hex) |
|---|---|---|---|
| Backspace | 08 | 8 |  |
| Tab | 09 | 9 | 9F |
| Escape | 1B | 27 |  |
| Delete | 7F | 127 | A0 |
| Up Arrow | 80 | 128 | A4 |
| Down Arrow | 81 | 129 | A1 |
| Left Arrow | 82 | 130 | A2 |
| Right Arrow | 83 | 131 | A3 |
| Insert | 84 | 132 |  |
| Home | 86 | 134 |  |
| End | 87 | 135 |  |
| Page Up | 88 | 136 |  |
| Page Down | 89 | 137 |  |
| F1 | 91 | 145 | B1 |
| F2 | 92 | 146 | B2 |
| F3 | 93 | 147 | B3 |
| F4 | 94 | 148 | B4 |
| F5 | 95 | 149 | B5 |
| F6 | 96 | 150 | B6 |
| F7 | 97 | 151 | B7 |
| F8 | 98 | 152 | B8 |
| F9 | 99 | 153 | B9 |
| F10 | 9A | 154 | BA |
| F11 | 9B | 155 | BB |
| F12 | 9C | 156 | BC |
| Print Screen | 9D | 157 | BD |
| Pause/Break | 9E | 158 |  |

For the function keys and Print Screen the Shift key adds 20 (hex) to the code (this is the equivalent of setting bit 5): for example Shift-F3 generates B3 (hex) and Shift-F10 generates BA (hex). The Shift key also gives the codes shown for Tab, Delete and the arrow keys, which the editor uses for its Shift-Tab, Shift-Delete and selection keys. It is ignored for the other keys in the table.

The Alt keys and the Control keys are modifiers: they do not generate a code of their own (with Control held down a letter key gives its control code, eg Ctrl-C gives 3). The state of the modifier keys is returned by KEYDOWN(7) and that of the lock keys by KEYDOWN(8).

MMBasic will translate the VT100 escape codes generated by terminal emulators such as Tera Term and Putty for the arrow keys, Insert, Delete, Home, End, Page Up, Page Down and F1 to F12 to these codes. Of the shifted keys only Shift-F3 is translated. This means that a terminal emulator operating over a USB or a serial port opened as console will generate the same key codes as a directly attached keyboard.
