=== OPTION ANGLE RADIANS | DEGREES
--- keep roomy
This command switches trig functions between degrees and radians.  Acts on SIN, COS, TAN, ATN, ATAN2, MATH ATAN3, ACOS and ASIN.
This is a temporary option that is reset to the default (RADIANS) when a program is run, when it ends, after an error and after CTRL-C, so it should be set at the top of any program that uses angles in degrees.  MM.INFO(OPTION ANGLE) returns the current setting.

=== OPTION AUTORUN ON
or
OPTION AUTORUN OFF
--- P keep roomy
Instructs MMBasic to automatically run the program in program memory on power up or restart (for example, by the WATCHDOG timer).  OFF is the default.  The program is not run after the restart that an OPTION command causes.
If the Colour Maximite 2 is set to run programs from RAM (OPTION RAM) MMBasic instead looks for the file AUTORUN.BAS on the SD card on power up or restart and runs it if it is found.
Entering the break key (default CTRL-C) at the console will interrupt the running program and return to the command prompt.
A firmware upgrade turns this option off.

=== OPTION BASE 0 | 1
--- keep roomy
Set the lowest value for array subscripts to either 0 or 1.
This must be used before any arrays are declared (otherwise the error is "Must be before DIM or LOCAL") and is reset to the default of 0 when a program is run.

# b14 does not say that it restarts (Src/MiscSTM32.c:1555) or that it and OVERCLOCK share one setting (Option.CPUmode).
=== OPTION BASELINE ON
or
OPTION BASELINE OFF
--- P keep roomy
OPTION BASELINE ON makes the Colour Maximite 2 run as a 400MHz Generation 1 machine.  This is intended to allow testing of code on the lowest common denominator.
OPTION BASELINE and OPTION OVERCLOCK cannot both be on: turning one on turns the other off, and OPTION BASELINE OFF (or OPTION OVERCLOCK OFF) returns to the normal speed.
This command will cause a reboot.

=== OPTION BAUDRATE nbr
--- P keep roomy
Set the baud rate for the serial console to ‘nbr’ (at least 100).  The default is 115200.  A Generation 2 runs well at 460800, but the USB to serial converter of a Generation 1 cannot run at that speed.
The new rate is saved and is used from the next restart (MMBasic replies "Restart to activate"): the terminal emulator must then be set to match.  A firmware upgrade returns it to 115200.
Using this command it is possible to set the console to an unworkable baud rate.  It can then be changed using a USB keyboard and VGA monitor, or returned to the default by resetting MMBasic (see Resetting MMBasic in the chapter Using MMBasic).
This command can only be run from the command line.

=== OPTION BREAK nn
--- keep roomy
Set the value of the break key to the ASCII value ‘nn’.  This key is used to interrupt a running program.
The break key is set to CTRL-C whenever MMBasic returns to the command prompt, but it can be changed to any keyboard key using this command in a program (for example, OPTION BREAK 4 will set the break key to the CTRL-D key).  Setting this option to zero will disable the break function entirely.  MM.INFO(OPTION BREAK) returns the current value.

=== OPTION CASE LOWER | UPPER | TITLE
--- P keep roomy
Change the case used for listing command and function names when using the LIST command.  The default is TITLE but the old standard of MMBasic can be restored using OPTION CASE UPPER.

=== OPTION COLOURCODE ON
or
OPTION COLOURCODE OFF
or
OPTION COLOURCODE REVERSE
--- P keep roomy
Turn on or off colour coding for the editor's output.  Keywords will be in cyan, comments in yellow, etc.  The default is ON.  Only BASIC programs (.bas files) are colour coded.
OPTION COLOURCODE REVERSE is the same as OPTION COLOURCODE OFF except that the editor and the file manager show black text on a white background.
The keyword COLORCODE (USA spelling) can also be used.
On the serial console colour coding requires a terminal emulator that can interpret the VT100 escape codes (for example, Tera Term).

=== OPTION CONSOLE BOTH [font [, fc [, bc]]]
or
OPTION CONSOLE SCREEN
or
OPTION CONSOLE SERIAL
or
OPTION CONSOLE NONE
--- roomy
OPTION CONSOLE SCREEN will disable the serial console for both input and output and direct all output to the VGA monitor.  This will allow the VGA output to update much faster.  With this option the serial port used for the console can be opened as COM3.
OPTION CONSOLE SERIAL will disable the console output to the VGA screen and send all output to the serial console.  This is useful for debugging graphics applications as diagnostic PRINT statements will not corrupt the screen display.
OPTION CONSOLE BOTH will enable both the serial console and the VGA screen for console input and output.  This is the default unless OPTION CONSOLE SAVE has saved another setting.  The optional ‘font’ (1 to 8), ‘fc’ and ‘bc’ set the font and the foreground and background colours of the console's text on the screen (by default white on black); OPTION CONSOLE SAVE keeps them.
OPTION CONSOLE NONE (the PicoMite's) sends the output to neither.  The serial console, if it was running, still takes input, so CTRL-C still works.
These settings are temporary: when a program ends or an error occurs the console returns to the saved setting.  OPTION CONSOLE BOTH and OPTION CONSOLE SERIAL give the error "Console port in use" while COM3 is open.  MM.INFO(OPTION CONSOLE) returns the current setting.

# b14 does not say that it restarts (Src/MiscSTM32.c:1640).  MM.INFO(OPTION CONSOLE PORT) is never reached:

=+= OPTION CONSOLE PORT n
--- P keep roomy
Selects the serial port used as the console: 1 (COM1), 2 (COM2) or 3 (the default: the serial over USB on the USB Type-B connector).  With 1 or 2 all console input and output goes through that port, which allows easier remote operation using a WiFi to UART module or a radio link (see ESP-01 Module in the chapter Colour Maximite 2 Generation 2), and COM3 is available on the USB Type-B connector.
This command will cause a reboot.  This setting is kept through a firmware upgrade.

=+= OPTION CONSOLE SAVE
--- P keep roomy
Saves the current console setting (OPTION CONSOLE BOTH, SCREEN, SERIAL or NONE) as the one used at power up and whenever a program ends.
If you are using the Colour Maximite 2 as a stand alone computer it is recommended that you execute OPTION CONSOLE SCREEN, then OPTION CONSOLE SAVE, to permanently disable the serial console and thereby eliminate serial I/O overhead.
This command will cause a reboot.

=== OPTION CRLF CR | LF | CRLF
--- keep roomy
Defines what the USB keyboard will send when the Enter key is pressed: CR (a carriage return), LF (a line feed) or CRLF (both, the default).
This command can only be used in a program.  The setting returns to CRLF when a program is loaded and when it ends.

=== OPTION DEFAULT FLOAT | INTEGER | STRING | NONE
--- keep roomy
Used to set the default type for a variable which is not explicitly defined.
If OPTION DEFAULT NONE is used then all variables must have their type explicitly defined or the error "Variable type not specified" will occur.
When a program is run the default is set to FLOAT for compatibility with Microsoft BASIC and previous versions of MMBasic.  MM.INFO(OPTION DEFAULT) returns the current setting.

=== OPTION DEFAULT MODE n
--- P roomy
Specifies the video mode for the command prompt, the editor and the file manager, which is also the mode a program starts in.  The colour depth is 8 bits.  ‘n’ can be:
1 = 800x600, 100 x 50 characters (the default)
8 = 640x480, 80 x 40 characters
9 = 1024x768, 102 x 48 characters
10 = 848x480, 106 x 40 characters (widescreen)
11 = 1280x720, 128 x 45 characters (widescreen)
12 = 960x540, 120 x 45 characters (widescreen, lines duplicated)
14 = 960x540, 120 x 45 characters (widescreen, lines not duplicated: preferred over 12 but not supported by all monitors)
15 = 1280x1024, 160 x 85 characters
16 = 1920x1080, 120 x 45 characters (widescreen, Generation 2 only)
18 = 1024x600, 102 x 37 characters
The characters are the columns and lines of the screen in the editor's font, which this option also sets: NORMAL (8x12 pixels) in modes 1, 8, 10, 12, 14 and 15, MEDIUM (10x16) in modes 9, 11 and 18 and VERY LARGE (16x24) in mode 16.  OPTION EDIT FONT can then change it.
This command can only be run from the command line and will cause a reboot.  This setting is kept through a firmware upgrade.

=== OPTION DS3231 ON
or
OPTION DS3231 OFF
--- P keep roomy
__GENERATION 2 ONLY__ Enables and disables the use of the optional DS3231 real time clock (see High Accuracy Real Time Clock in the chapter Colour Maximite 2 Generation 2) for providing the time and date.  If OPTION MILLISECONDS is ON the processor's internal clock is always used for the time.
On a Generation 1 this command gives the error "DS3231 not available on this H/W".
This command will cause a reboot.  This setting is kept through a firmware upgrade.

=== OPTION EDIT FONT SMALL | NORMAL | MEDIUM | LARGE | VERY LARGE
--- P keep roomy
Sets the font to be used in the editor and the file manager: SMALL (6x8 pixels), NORMAL (8x12, the default), MEDIUM (10x16), LARGE (12x20) or VERY LARGE (16x24).  OPTION DEFAULT MODE also sets it, to the font that suits the mode.
This command can only be run from the command line.  This setting is kept through a firmware upgrade.

=== OPTION ERROR ABORT
or
OPTION ERROR CONTINUE
--- keep roomy
Sets what happens when an operation on a file on the SD card or the USB drive fails (for example, opening a file that does not exist).  With OPTION ERROR ABORT (the default) the program stops with an error message.  With OPTION ERROR CONTINUE it continues, and MM.ERRNO and MM.ERRMSG$ report the error.
It is reset to ABORT when a program is run.  See also the ON ERROR command, which handles all errors.

=== OPTION ESCAPE [OFF]
--- keep roomy
Enables the ability to insert escape sequences into string constants.  See the section Special Characters in Strings in the chapter Variables and Expressions.
OPTION ESCAPE OFF will disable it.  It is turned off when a program is run, so OPTION ESCAPE should be placed at the start of the program.

=== OPTION EXPLICIT
--- keep roomy
Placing this command at the start of a program will require that every variable be explicitly declared using the DIM, LOCAL or STATIC commands before it can be used in the program.
This option is disabled by default when a program is run.  If it is used it should be placed before any variables are used.  MM.INFO(OPTION EXPLICIT) returns the current setting.

=== OPTION F11 string$
or
OPTION F12 string$
or
OPTION F15 string$
or
OPTION F16 string$
or
OPTION F19 string$
or
OPTION F20 string$
--- P keep roomy
Define the string that will be generated when a function key is pressed at the command prompt: F11, F12, F15 (Shift-F3), F16 (Shift-F4), F19 (Shift-F7) or F20 (Shift-F8).  The maximum string length is 63 characters.  Setting the string to "" removes it.
If the string ends with a carriage return and line feed the command is run at once.  Example:
`OPTION F11 "RUN " + CHR$(34) + "myprog" + CHR$(34) + CHR$(13) + CHR$(10)`
The other function keys are fixed (see Shortcut Keys in the chapter Using MMBasic).

=== OPTION FLASH [n]
--- P keep roomy
Specifies that programs are to be run from flash memory (the default), so that the program is preserved when the Colour Maximite 2 is powered off or reset.  It undoes OPTION RAM.
The flash is not written every time a program is run: it is only written if it does not match the newly tokenised program, ie, a different or altered program is being loaded.
The optional parameter ‘n’ (1 to 6, default 1) specifies where the program starts, in 128KB sectors of the flash: the maximum program size is 512KB for ‘n’ of 1 to 3, 384KB for 4, 256KB for 5 and 128KB for 6.  Moving the program can spread the wear on the flash, although this is unlikely ever to be needed.  A library saved in flash uses sector 6 (see the LIBRARY command), which a program then cannot use (the error is "Library is using flash slot 6").
This command can only be run from the command line and will cause a reboot.

# b14 does not say that it restarts (Src/MiscSTM32.c:1387).  It is not kept through a firmware upgrade (Src/flash.c:576)
# and OPTION LIST does not show it.
=== OPTION HORIZONTAL OFFSET mode, offset
--- P keep roomy
Since different VGA monitors and HDMI converters interpret the analog sync signals slightly differently, the screen image may appear off-centre (eg, a black bar on one side or the edge of the text being cut off).  This command allows you to calibrate the Colour Maximite 2's signal to match your specific hardware without needing to use the monitor's adjustment buttons every time.
For each ‘mode’ (1 to 18), ‘offset’ is an adjustment in pixels to the start of the horizontal lines on the VGA display.  The default is 0 and the allowed range is -128 to 127.
This command will cause a reboot.

=== OPTION KEYBOARD REPEAT firstchar, nextchar
--- P keep roomy
Define the repeat characteristics of the USB keyboard when a key is held down.
‘firstchar’ is the time in milliseconds before the key first repeats: the default is 500 mSec and the valid range is 100 to 2000 mSec.
‘nextchar’ is the time in milliseconds between its subsequent repeats: the default is 75 mSec and the valid range is 25 to 2000 mSec.

The commands LINE, CIRCLE and PIXEL use the legacy syntax, all drawing commands (and COLOUR) will accept colours in the range of 0 to 7, and fonts 1 to 3 are those of the original Colour Maximite. --- keep roomy
This command is accepted, for programs written for the PicoMite, and ignored.  On the PicoMite it sets how many of the variables are kept for local variables; the Colour Maximite 2 already has room for more local variables than it can set.  ‘n’ must be 1 to 100000.

=== OPTION MAXCTRLS n
--- P keep roomy
Sets the number of GUI controls that a program can create (see the chapter GUI Controls).  ‘n’ can be 0 to 2000 and the controls are numbered 1 to ‘n’.  The default is 0, and then a program that creates a control stops with the error "No memory allocated for GUI controls".

=== OPTION MILLISECONDS ON
or

--- keep roomy
Specifies that the TIME$ function will, or will not, include milliseconds as a decimal fraction of the seconds in its output (HH:MM:SS.mmm).  The default is OFF.
The milliseconds come from the processor's internal clock, so while this option is ON the internal clock provides the time even if OPTION DS3231 is ON.
The option is not saved: it returns to OFF when a program ends or an error occurs.

=== OPTION MOUSE channel [, sensitivity]
or
OPTION MOUSE OFF
--- P roomy
Sets the mouse used by the editor and the GUI controls.  ‘channel’ is 0 for a PS2 mouse, or 1 to 3 for a Hobbytronic USB mouse interface on that I^^2^^C channel.  The optional ‘sensitivity’ can be 0 to 8 for a PS2 mouse and 0 to 10 for the Hobbytronic interface (see Mouse Support in the chapter Hardware Features).
While this option is set, a USB mouse plugged into the USB connector is used by the editor in place of the mouse set here.  The GUI controls use the channel set here, which must be 2 for a USB mouse.
If a Hobbytronic interface is set but not connected the error "Mouse not connected" is reported when the editor is started.
OPTION MOUSE OFF (the default) disables it.  MM.INFO(OPTION MOUSE) returns the channel, or -1 when it is off.
This command can only be run from the command line and will cause a reboot.  This setting is kept through a firmware upgrade (the sensitivity returns to 0).

=== OPTION MOUSE SENSITIVITY n
--- P keep roomy
Sets the speed of a USB mouse: its movement is divided by ‘n’, so a number above 1 slows the mouse down and a number below 1 speeds it up.  ‘n’ can be 0 to 1000 and need not be a whole number; 0 or 1 (the default) leaves the mouse as it is.  The setting applies at once, in the editor and in programs.
The firmware always reads the full report of a USB mouse (its wheel and all its buttons), so unlike the PicoMite this option does not change how the mouse is read.
This command can only be run from the command line.

=== OPTION OVERCLOCK ON
or
OPTION OVERCLOCK OFF
--- P keep roomy
OPTION OVERCLOCK ON runs the processor at 504MHz in place of 480MHz (or 400MHz on processors of revision Y).  This is the fastest speed at which most of both the original and the Generation 2 versions of the Colour Maximite 2 run reliably.
OPTION OVERCLOCK and OPTION BASELINE cannot both be on: turning one on turns the other off, and OPTION OVERCLOCK OFF (or OPTION BASELINE OFF) returns to the normal speed.
This command will cause a reboot.

=== OPTION PIN nbr
--- P roomy
Set ‘nbr’ as the PIN (Personal Identification Number) for access to the console prompt.  ‘nbr’ can be any non zero number of up to eight digits.
Whenever a running program tries to exit to the command prompt for whatever reason MMBasic will request this number before the prompt is presented.  This is a security feature as without access to the command prompt an intruder cannot list or change the program in memory or modify the operation of MMBasic in any way.  To disable this feature enter zero for the PIN number (ie, OPTION PIN 0).
A permanent lock can be applied by using 99999999 for the PIN number: the console then only offers a restart.
If a permanent lock is applied or the PIN number is lost the only way to recover is to reset MMBasic to its original configuration, which erases the program (see Resetting MMBasic in the chapter Using MMBasic).

# costs about 5%: the profiler now takes its counters from the heap at RUN (Src/MMBasic.c:352, 8 bytes a source line) and

=== OPTION PROFILING ON
or
OPTION PROFILING OFF
--- P keep roomy
Turns the profiler on or off.  While it is on, each time a program is run MMBasic counts how many times each line of the program runs and the time spent in it.  After the program has run, LIST PROFILE lists the program with, in front of each line, the number of times it ran and the average time it took in microseconds, and LIST PROFILE CSV writes the same to a file named after the program with the extension .CSV.
The counters take 8 bytes of the heap for each line of the program, and collecting them makes the program run a little slower.  MM.INFO(OPTION PROFILING) returns the current setting.
This command will cause a reboot.

# b14 does not say that it is for the command line only or that it restarts (Src/MiscSTM32.c:1417).  The program memory
# is cleared at every boot (Src/main.c:807); AUTORUN.BAS: Src/main.c:914; the memory: 23_characteristics.md.
=== OPTION RAM
--- P keep roomy
Causes programs to be loaded into RAM to run rather than into flash memory.  This makes loading somewhat faster and avoids wearing the flash.  Program performance is similar to running from flash.
The program is lost when the power is removed, on a reset and when an option that restarts MMBasic is changed.  On the Generation 1 the memory available for variables is reduced by 512KB; on the Generation 2 it is not.
With OPTION AUTORUN ON, MMBasic runs the file AUTORUN.BAS from the SD card on power up.  OPTION FLASH returns to running programs from flash.
This command can only be run from the command line and will cause a reboot.

=== OPTION RESET
--- P keep roomy
Reset all saved options to their default values (those kept through a firmware upgrade too).  The program in program memory and the saved variables are not erased.
This command can only be run from the command line and will cause a reboot.

=== OPTION RTC CALIBRATE n
--- P keep roomy
Used to calibrate the battery backed real time clock that keeps time in the Colour Maximite 2.
‘n’ is a number between -511 and +512.  A change of ±1 should equate to about 0.0824 seconds per day.  Negative numbers will slow the clock down, positive will speed it up (different from the Micromite).
This setting is kept through a firmware upgrade.

# Not in b14.  Src/MiscSTM32.c:1474: 0 to 3, the drive of the clock's 32.768kHz crystal oscillator (LSE, Src/main.c:607);
# the default 2 (Src/flash.c:547).
=== OPTION RTC DRIVE n
--- P keep roomy
Sets the drive strength of the oscillator for the real time clock's 32.768kHz crystal: 0 (low), 1 (medium low), 2 (medium high, the default) or 3 (high).  A higher drive can help a crystal that is slow to start; a lower one takes less current from the battery.
This command can only be run from the command line and will cause a reboot.  This setting is kept through a firmware upgrade.

=== OPTION SD TIMING NORMAL
or
OPTION SD TIMING FAST
--- P keep roomy
The fast option will speed up the timing for SD card access.  This results in read/write speeds being about 20% faster where cards can accommodate the higher speed access.  The default is NORMAL.
This command can only be run from the command line and will cause a reboot.  This setting is kept through a firmware upgrade.

=== OPTION SEARCH PATH pathname$
or
OPTION SEARCH PATH DISABLE
--- P keep roomy
Defines a directory which will be searched when a program is run from the command prompt with the RUN command or its short form (\*), or with EXECUTE, and the file does not exist in the current directory.  ‘pathname$’ must start and end with a forward slash (eg, "/programs/") and can be up to 127 characters long.
OPTION SEARCH PATH DISABLE removes it.  MM.INFO(SEARCH PATH) returns it.

=== OPTION SLEEP n
--- P keep roomy
Turns the monitor off (the VGA sync signals are stopped, so that the monitor goes into its power saving mode) when no key has been pressed at the command prompt for ‘n’ minutes (1 to 255).  Any key press will wake the monitor.  Set ‘n’ to 0 (the default) to disable this.

=== OPTION STATUS ON | OFF
--- P keep roomy
Enable or disable the status line at the bottom of the VGA screen at the command prompt.  The status line shows the current directory, the "current program filename" used by the commands RUN, LIST and EDIT when a file name is not specified, and the time and date.  The default is ON.
This command can only be run from the command line.

=== OPTION SYMBOLS OFF
--- keep roomy
This command is accepted, for programs written for the PicoMite, and changes nothing.  On the PicoMite it makes a program run without the symbol tables that MMBasic normally builds, to save the memory they use.
As on the PicoMite, it must be the first command in the program (only blank lines and comments can come before it) and it cannot be used at the command prompt; elsewhere it gives an error.

=== OPTION TAB 2 | 3 | 4 | 8
--- P keep roomy
Set the spacing for the tab key in the editor.  The default is 2.

=== OPTION USB POLLING n
--- P keep roomy
Sets how often, in milliseconds, MMBasic services the devices on the USB connector (the keyboard, the mouse, the gamepads, USB serial ports and the USB drive) and does its other routine checks.  ‘n’ can be 1 to 64; the default is 2.  A smaller value makes the devices more responsive and a larger one leaves a little more time for the program.
This command can only be run from the command line.

# b14 lists US, UK, DE, FR and ES: the handler takes BE too (Src/MiscSTM32.c:1356), and DISABLE (MiscSTM32.c:1346), which
# sets NO_KEYBOARD: Src/USBKeyboard.c:451-462 then uses the UK layout and the keyboard still works (a leftover, I think).
=== OPTION USBKEYBOARD nn [, noLED]
or
OPTION USBKEYBOARD DISABLE
--- P keep roomy
Set the layout of the USB keyboard.  ‘nn’ is a two character code: US for the standard keyboard layout in the USA, Australia and New Zealand, UK for the United Kingdom (the default), DE for Germany, FR for France, ES for Spain and BE for Belgium.  The layout is also asked for when MMBasic is first loaded.
The optional ‘noLED’ parameter can be set to 1 to block sending the command to the keyboard that lights the LEDs relating to Caps Lock etc.  This may be needed on some keyboards which do not process this command properly and may lock up.  It defaults to 0 if not specified (ie, the LED commands are sent).
OPTION USBKEYBOARD DISABLE is accepted, from earlier versions, but the keyboard still works, with the UK layout.  MM.INFO(OPTION USBKEYBOARD) returns the layout.
This command can only be run from the command line and will cause a reboot.  This setting is kept through a firmware upgrade.

# Src/MM_Misc.c:2656: 1.8 to 3.6 ("VCC too low", "VCC too high"); not saved, and nothing resets it but a restart.
=== OPTION VCC voltage
--- keep roomy
Specifies the voltage (Vcc) supplied to the ARM Cortex-M7 chip, from 1.8 to 3.6.  When using the analog inputs to measure voltage the chip uses its supply voltage (Vcc) as its reference.  This voltage can be accurately measured using a DMM and set using this command for more accurate measurement.
The parameter is not saved and should be initialised either on the command line or in a program.  The default if not set is 3.3.

=== OPTION VGA OUTPUT HIGH | MEDIUM | LOW
--- P keep roomy
Selects the colour look up table (CLUT) used to drive the VGA output: HIGH (the default) drives each colour up to its full level, MEDIUM up to about 7/8 of it and LOW up to 3/4.  MEDIUM and LOW make the picture darker, for a monitor that shows it too brightly.
This command can only be run from the command line and will cause a reboot.

=== OPTION Y\_AXIS DOWN | UP
--- keep roomy
This command can only be used in a program and inverts the y axis for the drawing commands: with UP, 0,0 is at the bottom left as in a typical graphing application.  This is a temporary option that is reset to the default (DOWN) when programs end, after an error and after CTRL-C.  MM.INFO(OPTION Y\_AXIS) returns the current setting.
