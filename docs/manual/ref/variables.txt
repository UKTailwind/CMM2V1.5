# Predefined Read Only Variables: the reference entries (tools/manual/reftext.py)

=== MM.CMDLINE$
--- keep
A string holding the command line arguments passed to the program: the text after the file name and its comma in the RUN command (eg, RUN "myprog", -f 3), the text after the file name in the \* shortcut (eg, \*myprog -f 3) or the ‘cmdline$’ of CHAIN.  The text given to RUN is not processed by MMBasic, so it can contain numbers, commas, quoted strings, etc: it is for the program to decode.
It is an empty string when the program was run without arguments, from the editor (F2) or by OPTION AUTORUN.

=== MM.DEVICE$
--- keep
A string identifying the computer that MMBasic is running on: "Colour Maximite 2" on a Generation 1 and "Colour Maximite 2 G2" on a Generation 2.  Other versions of MMBasic return their own name (eg, a PicoMite's), so a program can use it to tell which computer it is running on.

=== MM.ERRNO
MM.ERRMSG$
MM.ERRLINE
---
If a statement caused an error which was ignored (see ON ERROR) these variables will be set accordingly.  MM.ERRNO is a number where non zero means that there was an error and MM.ERRMSG$ is a string holding the error message that would normally have been displayed on the console (without the "Error in line n:" in front of it).
MM.ERRLINE is the number of the line that caused the error, as the error message gives it: a line of the program's file or, when the message names one, of an #INCLUDE file or of the library's file.  It is zero if the error did not occur in a program line (eg, at the command prompt).
They are reset to zero and an empty string by RUN and by ON ERROR IGNORE, SKIP, CLEAR and RESTART.

=== MM.FLAGS
--- keep
The value of the system flag register, which the FLAG and FLAGS commands set (see also the FLAG() function).

=== MM.FONTHEIGHT
MM.FONTWIDTH
--- keep
Integers holding the height and the width, in pixels, of the characters of the current font, including its scaling (see FONT).

=== MM.HEIGHT
MM.WIDTH
--- keep
MM.HEIGHT is the number of lines of characters down the display and MM.WIDTH the number of characters across it, with the current font.  When PAGE WRITE has selected another page they are for that page.

=== MM.HPOS
MM.VPOS
--- keep
The current horizontal and vertical position (in pixels) following the last graphics or PRINT command.

=== MM.HRES
MM.VRES
--- keep
Integers holding the horizontal and vertical resolution, in pixels, of the display in the current video mode (see MODE), or of the page or framebuffer being written to when PAGE WRITE or FRAMEBUFFER WRITE has selected another.

=== MM.I2C
--- keep
Following an I^^2^^C write or read command this integer variable will be set to indicate the result of the operation as follows:
{l=720}0 = The command completed without error.
{l=720}1 = Received a NACK response
{l=720}2 = Command timed out
After I2C CHECK it is 0 if a device responded and non zero if none did.  See Appendix B.

=== MM.INFO()
MM.INFO$()
--- keep
MM.INFO returns information about the system: the keyword (or keywords) in the brackets says which, as listed in the rows below.  The two versions can be used interchangeably (MM.INFO$ is turned into MM.INFO when the line is entered) but good programming practice would require that you use the one corresponding to the returned datatype: MM.INFO$ where the value is a string.

=+= MM.INFO$(DEVICE)
MM.INFO(VERSION)
MM.INFO(ERRNO)
MM.INFO$(ERRMSG)
MM.INFO(I2C)
MM.INFO(ONEWIRE)
MM.INFO(FONTHEIGHT)
MM.INFO(FONTWIDTH)
MM.INFO(HPOS)
MM.INFO(VPOS)
--- keep
The same as MM.DEVICE$, MM.VER, MM.ERRNO, MM.ERRMSG$, MM.I2C, MM.ONEWIRE, MM.FONTHEIGHT, MM.FONTWIDTH, MM.HPOS and MM.VPOS.

=+= MM.INFO(BBC BUFFER [n])
--- keep
The number of free slots in the PLAY BBC SOUND queue of channel ‘n’ (0 to 3), or in the emptiest of the four channels if ‘n’ is omitted.  Each channel queues up to 16 notes.

=+= MM.INFO(BCOLOUR)
MM.INFO(FCOLOUR)
--- keep
The current background and foreground colours (see COLOUR).  BCOLOR and FCOLOR are accepted too.

=+= MM.INFO(CODE SIZE)
--- keep
The size, in bytes, of the program in program memory, as MMBasic prepared it when it was loaded (see LIST FLASH).

=+= MM.INFO$(COMPILE)
--- keep
What OPTION COMPILE did at the last RUN: OFF; "TEXT: " and why the program ran as text (eg, too big for the area, with the bytes it needed of those there are); or COMPILED followed by the number of compiles since the Colour Maximite 2 started (REUSED: the times the program had not changed), the statements in the compiled program (STMTS), those the last run executed from it (RAN), a count for testing the compiler (MISS), the statements run as compiled code (CODE), then its size of the area's (SIZE n OF m).  Once a command has been typed at the command prompt it begins NONE instead of COMPILED.

=+= MM.INFO(CPUSPEED)
--- keep
The speed of the processor's clock in Hz, as a number: 400000000 for the Rev Y version of the STM32H743 and 480000000 for the Rev V (see the chapter Hardware Features), or 504000000 with OPTION OVERCLOCK ON.  (The PicoMite returns the speed as a string: a PicoMite program that reads MM.INFO$(CPUSPEED) into a string needs STR$() here.)

=+= MM.INFO$(CURRENT)
MM.INFO$(PATH)
MM.INFO$(DIRECTORY)
--- keep
MM.INFO$(CURRENT) is the full name of the file that the program in program memory was loaded from, with its drive and directory (eg, "A:/GAMES/PACMAN.BAS"), or "NONE" if there is no program (eg, after NEW).  This is the current program, which RUN, EDIT and LIST use when they are given no file name.
MM.INFO$(PATH) is the drive and directory of that file, ending with a "/" (eg, "A:/GAMES/"), or "NONE".  A program can use it to find the files it needs relative to itself.
MM.INFO$(DIRECTORY) is the current directory, with its drive and ending with a "/" (eg, "A:/GAMES/").  See also CWD$.

=+= MM.INFO(DISK SIZE)
MM.INFO(FREE SPACE)
MM.INFO$(DRIVE)
--- keep
The size and the free space, in bytes, of the active drive (the SD card, or the USB flash drive when C: is the active drive), and the active drive itself: "A:" or "C:" (B:, the SD card's other name, is reported as "A:").  See DRIVE.

=+= MM.INFO(EXISTS FILE file$)
MM.INFO(EXISTS DIR dir$)
--- keep
1 if the file ‘file$’ exists and 0 if it does not (or if ‘file$’ is a directory), and 1 if the directory ‘dir$’ exists and 0 if it does not.  The names can include a drive and a path.  A directory on C: is reported as not existing when no USB flash drive is plugged in.

=+= MM.INFO(FILESIZE file$)
MM.INFO$(MODIFIED file$)
--- keep
The size of the file ‘file$’ in bytes: -1 if it is not found and -2 if it is a directory.
The date and time that ‘file$’ was last modified, as a string in the form "YYYY-MM-DD HH:MM:SS".  ‘file$’ can also be a directory.  It is an empty string if the file or directory is not found.

=+= MM.INFO(FLASH)
--- keep
The slot whose program is running: a flash slot, 1 to 3 (see FLASH RUN and FLASH CHAIN), or a RAM slot, 1 to 5 (see RAM RUN and RAM CHAIN), or 0 for the program in program memory.

=+= MM.INFO(FLASH ADDRESS n)
--- keep
The address of slot ‘n’ (1 to 8), as FLASH LOAD IMAGE, FLASH DISK LOAD and FLASH SAVE fill it: an image's first two 32-bit words are its width and height.  A flash slot (1 to 3) is read from the SD card into RAM when it is first used after a RUN or NEW.  An empty flash slot reads as erased flash memory (every byte &HFF), and an empty RAM slot (4 to 8) as a header whose width and height are zero, as on the PicoMite.

=+= MM.INFO(FONT)
MM.INFO(FONT ADDRESS n)
MM.INFO(FONT POINTER n)
--- keep
The number of the current font (see FONT).
The address in memory of the data of font ‘n’ (1 to 16, 0 if there is no such font), and (POINTER) the address of the entry of MMBasic's font table that holds that address.

=+= MM.INFO(FRAMEBUFFER)
MM.INFO(FRAMEH)
MM.INFO(FRAMEV)
--- keep
The address in memory of the framebuffer made by FRAMEBUFFER CREATE (0 if there is none), and its width and height in pixels.  The address is useful if you need to PEEK or POKE its contents.  In the 4-bit colour depth FRAMEBUFFER makes the PicoMite's framebuffers, which are pages: use MM.INFO(WRITEBUFF) or MM.INFO(PAGE ADDRESS n) for them (see FRAMEBUFFER).

=+= MM.INFO(HARDWARE)
--- keep
1 on a Generation 1 Colour Maximite 2 and 0 on a Generation 2.

=+= MM.INFO(HEAP)
MM.INFO(IHEAP)
MM.INFO(SHEAP)
MM.INFO(MINHEAP)
--- keep
The free space, in bytes, of the MMBasic heap, which holds strings, arrays, framebuffers and other buffers.  MM.INFO(HEAP) is the total of the heap in the processor's RAM, MM.INFO(IHEAP), and the heap in the SDRAM, MM.INFO(SHEAP) (which does not count the top 512KB of the SDRAM, kept for the code of a RAM library's CSUBs).  HEAPI and HEAPS are accepted as other names for IHEAP and SHEAP.  See the memory map in the chapter MMBasic Characteristics.
MM.INFO(MINHEAP) is the lowest address that the heap in the SDRAM, which is used from the top down, has reached since it was last cleared (by RUN, NEW or loading a program).

=+= MM.INFO$(ID)
MM.INFO(ID48)
--- keep
The unique 12 byte ID of the processor as a string of 24 hexadecimal digits, and a 48-bit hash of it as an integer.  The hash is not guaranteed to be unique world wide but most likely is: it is suitable as a serial number for the device and fits in a CAN message.

=+= MM.INFO$(KEYBOARD)
--- keep
"Connected" if a USB keyboard is connected and working, otherwise "Not Connected".

=+= MM.INFO(LINES)
--- keep
The number of lines of source code in the program in program memory: the lines read from its file and its #INCLUDE files when it was loaded.

=+= MM.INFO(MAX PAGES)
MM.INFO(PAGE ADDRESS n)
MM.INFO(WRITE PAGE)
MM.INFO(WRITEBUFF)
--- keep
The highest page number that can be selected in the current video mode (see MODE and PAGE), and the address in memory of page ‘n’ (0 to MM.INFO(MAX PAGES)), which is useful to PEEK or POKE the contents of a page (see Video Memory in the chapter Video Modes and Pages).
MM.INFO(WRITE PAGE) and MM.INFO(WRITEBUFF) (the PicoMite's name) are the address of the page that the drawing commands write to (see PAGE WRITE and FRAMEBUFFER WRITE).

=+= MM.INFO(MODE)
--- keep
The current video mode and colour depth as a number: the mode, then the depth as its decimals (eg, 1.8 for MODE 1,8, 8.16 for MODE 8,16, 1.12 for MODE 1,12 and 7.4 for MODE 7,4).

=+= MM.INFO$(OPTION option)
---
The current setting of one of the options that affect how a program runs.  ‘option’ is one of:
{l=720}ANGLE: "RADIANS" or "DEGREES" (see OPTION ANGLE)
{l=720}AUTORUN: "On" or "Off"
{l=720}BASE: 0 or 1 (a number)
{l=720}BREAK: the character code of the break key (a number: 3 for Ctrl-C, 0 when it is disabled)
{l=720}CONSOLE: "Serial", "Screen", "Both" or "None"
{l=720}CONSOLE PORT: the serial port the console uses, 1 to 3 (a number: see OPTION CONSOLE PORT)
{l=720}DEFAULT: "Integer", "Float", "String" or "None"
{l=720}EXPLICIT: "On" or "Off"
{l=720}LEGACY: "On" or "Off"
{l=720}MOUSE: the channel set by OPTION MOUSE (a number), or -1 when none is set
{l=720}PROFILING: "On" or "Off"
{l=720}USBKEYBOARD: the layout of the USB keyboard: "UK", "US", "DE", "FR", "ES", "BE" or "IT", or "Disabled" (OPTION USBKEYBOARD DISABLE)
{l=720}Y_AXIS: "UP" or "DOWN"

=+= MM.INFO(OVERRUN)
--- keep
The number of samples that the last ADC START could not take because the next one was due before the conversion of the one before had finished: zero unless the sampling frequency was too high (see ADC).

=+= MM.INFO$(PIN pinno)
--- keep
The status of I/O pin ‘pinno’ of the rear connector: "Unused", "In Use", "Reserved" (used by the Colour Maximite 2 itself) or "Invalid" (not an I/O pin).

=+= MM.INFO$(PLATFORM)
MM.INFO$(SYSTEM I2C)
--- keep
These are the PicoMite's.  On the Colour Maximite 2 both return an empty string, as a PicoMite with no OPTION PLATFORM and no OPTION SYSTEM I2C does, so that PicoMite programs that check them run.

=+= MM.INFO(PROGRAM)
MM.INFO(STACK)
MM.INFO(HEAPEND)
--- keep
The address in memory of the start of program memory (in the flash memory, or in the SDRAM with OPTION RAM), the current value of the processor's stack pointer, and the lowest the stack may go (the PicoMite's name): below it a program stops with the error "Stack overflow".

=+= MM.INFO(PSRAM SIZE)
--- keep
The size of the SDRAM in bytes: 8388608 (8MB) on a Generation 1 and 33554432 (32MB) on a Generation 2.  This is the PicoMite's key for its PSRAM, which PicoMite programs read to see whether they can use the image slots 4 to 8 and the RAM commands: on the Colour Maximite 2 they can (see FLASH LOAD IMAGE and RAM SAVE).

=+= MM.INFO$(RESET)
--- keep
The cause of the last restart: "Power-On" (the power was applied), "Switch" (the reset switch was pressed) or "Software" (a restart by MMBasic: CPU RESTART, a WATCHDOG timeout, or an OPTION command that restarts the Colour Maximite 2).  It can be read once: afterwards it is an empty string.

=+= MM.INFO(RTC)
--- keep
1 if an external DS3231 real time clock is in use (OPTION DS3231 ON), otherwise 0.

=+= MM.INFO(SAMPLE PLAYING n)
--- keep
1 if channel ‘n’ (1 to 4) of PLAY MODSAMPLE is playing a sample, otherwise 0.

=+= MM.INFO$(SDCARD)
--- keep
The status of the SD card: "Ready", "Not present" or "Unused" (a card is in the slot but has not been used yet).

=+= MM.INFO$(SEARCH PATH)
--- keep
The directory set by OPTION SEARCH PATH, in which RUN at the command prompt looks for a program that is not in the current directory.

=+= MM.INFO$(SOUND)
MM.INFO$(TRACK)
--- keep
What the audio output is doing: "OFF", "TONE", "WAV", "FLAC", "MP3", "MOD", "SOUND", "TTS", "ARRAY", "SAMPLE", "BBC" or "DAC" (the DAC command), or "PAUSED" followed by a space and what is paused (eg, "PAUSED WAV").
The name of the WAV, FLAC, MP3 or MOD file that is playing (or paused), or "OFF".

=+= MM.INFO(UPTIME)
--- keep
The time since the Colour Maximite 2 was restarted, in seconds, as a floating point number.

=+= MM.INFO(VARCNT)
--- keep
The number of variables in use: the global variables and the local variables of the subroutines and functions that are running.  ERASE, CLEAR and the end of a subroutine or function lower it.

=== MM.ONEWIRE
--- keep
Following a 1-Wire reset (ONEWIRE RESET, or ONEWIRE READ or WRITE with a reset) this integer variable is set to 1 if a device responded and to 0 if none did.  See Appendix C.

=== MM.VER
--- keep
The version number of the firmware as a floating point number in the form aa.bbccdd, where aa is the major version number, bb the minor version number, cc the revision number and dd the beta number (none for a release).  For example version 6.03.01 returns 6.0301 and version 7.00.00b2 returns 7.000002.  A release candidate's dd is its number plus 50 (6.04.00RC1 returns 6.040051), so it is above every beta of the same version.

=== MM.WATCHDOG
--- keep
An integer which is true (1) if MMBasic was restarted as the result of a watchdog timeout (see the WATCHDOG command), otherwise false (0).  It stays true until a program ends, so the program that OPTION AUTORUN runs after the restart can see it.
