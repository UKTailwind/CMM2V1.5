# Predefined Read Only Variables: the reference entries (tools/manual/reftext.py)

=== MM.VER
---
Returns the version number of the firmware as a floating point number in the form aa.bbcc where aa is the major version number, bb is the minor version number and cc is the revision number.  For example version 6.03.00 would return 6.03 and version 6.03.01 will return 6.0301.
{}

=== MM.DISPLAY
---

=== MM.ERRNO 
MM.ERRMSG$
MM.ERRLINE
---
If a statement caused an error which was ignored these variables will be set accordingly.  MM.ERRNO is a number where non zero means that there was an error and MM.ERRMSG$ is a string representing the error message that would have normally been displayed on the console.  They are reset to zero and an empty string by RUN, ON ERROR IGNORE or ON ERROR SKIP.
MM.ERRLINE is the number of the program line that caused the error.  It is zero if the error did not occur in the program (eg, at the command prompt or in the library) and it is reset to zero along with the other two variables.

---
{b=0}An integer which is true if MMBasic was restarted as the result of a Watchdog timeout (see the WATCHDOG command) otherwise false.
