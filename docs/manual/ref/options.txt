=== OPTION ANGLE RADIANS | DEGREES
--- roomy
This command switches trig functions between degrees and radians. Acts on SIN, COS, TAN, ATN, ATAN2, MATH ATAN3, ACOS, ASIN

=== OPTION AUDIO PWMnApin, PWMnBpin
or
OPTION AUDIO DISABLE
--- P roomy
__NOT BLUETOOTH HOST VERSIONS __Configures one of the PWM channels as an audio output.
‘PWMnApin’ is the left audio channel, ‘PWMnBpin’ is the right.  Both pins must belong to the same audio channel.
Example,  OPTION AUDIO GP18, GP19 would use PWM1A and PWM1B on pins 24 and 25 respectively.
This option prevents use of these pins in the BASIC program. 
The audio output is generated using PWM so a low pass filter is necessary on the output.  The audio output from the Raspberry Pi Pico is very noisy.  Using OPTION POWER and/or supplying power via a separate 3.3V linear regulator can reduce this.
This command must be run at the command prompt (not in a program).

=== OPTION AUDIO BLUETOOTH [idle]
or
OPTION AUDIO DISABLE
--- P roomy
__BLUETOOTH HOST VERSIONS ONLY __Directs the audio output to a Bluetooth speaker or headphones, which are connected with the BLUETOOTH CONNECT command.  No I/O pins are used.  See the chapter Bluetooth Versions for the details.
‘idle’ is the time in seconds (0 to 250) after the last sound before the audio stream to the speaker is suspended.  The stream starts as soon as the speaker connects, and once suspended it is restarted automatically by the next sound, which is delayed slightly while it starts.  0 means that the stream is never suspended.  The default is 60 seconds.
If Bluetooth is not already the audio output the PicoMite will restart after this command.  If it is, the command just changes ‘idle’.
This command must be run at the command prompt (not in a program).

=== OPTION AUTOREFRESH OFF | ON
--- roomy
__NOT VGA OR HDMI VERSIONS __Black and white displays can only be updated a full screen at a time. By using OPTION AUTOREFRESH OFF/ON you can control whether a write command immediately updates the display or not. If AUTOREFRESH is OFF the REFRESH command can be used to trigger the write. This applies to the following displays: N5110, SSD1306I2C, SSD1306I2C32, SSD1306SPI and ST7920

=== OPTION AUTORUN ON [,NORESET]
or
OPTION AUTORUN n [,NORESET]
or
OPTION AUTORUN OFF
--- P keep roomy
Instructs MMBasic to automatically run a program on power up or restart.  
ON will cause the current program in program memory to be run.  
Specifying ‘n’ will cause that location in flash memory to be run.  ‘n’ must be in the range 1 to 3.
Specifying the optional parameter “NORESET” will maintain AUTORUN even if the program causes a system error (by default this will cause the firmware to cancel any OPTION AUTORUN setting).
OFF will disable the autorun option and is the default for a new program.
Entering the break key (default CTRL-C) at the console will interrupt the running program and return to the command prompt.

=== OPTION COMPILE ON
or
OPTION COMPILE SHADOW
or
OPTION COMPILE OFF
{}
--- P roomy
__RP2350 VERSIONS ONLY __Controls the compiler.  With ON, RUN compiles the program (and its library, if there is one) into a stream of native operations and runs that.  Statements that the compiler cannot take run on the interpreter as before, interleaved with the compiled ones, so a program does not need to be changed and gives exactly the same results.
{t=l387}SHADOW compiles in the same way but also works out every compiled value again with the interpreter, and stops at the first statement where the two disagree.  It is slower than ON and is meant for checking a program.  OFF (the default) interprets the program only.
{t=l387}The setting takes effect at the next RUN and is saved with the other options.  A program is compiled again only when it, or its library, has changed since the last compile, so the first RUN after an edit takes a little longer.  MM.INFO$(COMPILE) reports what the last RUN compiled and how much of the program ran compiled, and OPTION PROFILING ON lists the statements that ran on the interpreter.
{t=l387}With PSRAM the compiled program is kept in PSRAM reserved by the firmware; without PSRAM it is kept in flash after the program memory.

=== OPTION CONSOLE output
--- roomy

=== OPTION CONTINUATION LINES ON/OFF
--- P roomy
Enables or disables the use of continuation lines in the editor and with the LIST command. Line continuation is indicated by a space followed by an underscore character at the end of a line. When enabled the editor will automatically split lines as it reads them from file and add the continuation characters required. When exiting the editor, the continuation characters are removed before saving. While in the editor the user can create long lines by adding their own continuation characters. This makes using a small screen as a console much easier.

=== {}
OPTION CPUSPEED speed
--- P keep roomy
__NOT VGA OR HDMI VERSIONS__
Change the CPU clock speed.
‘speed’ is the CPU clock in KHz.  The permitted range depends on the version: 48000 to 420000 on the PicoMite versions, 126000 to 396000 on the WebMite versions, and 200000 to 396000 on the Bluetooth versions.  Speeds above 200MHz (150MHz on the RP2350) are regarded as overclocking as those are the chip manufacturer’s specified maximums.
The default speed is 200000 on both the RP2040 and the RP2350.  
This command must be run at the command prompt (not in a program).  
See also the CPU SPEED command which changes the clock speed immediately, without saving it or restarting the firmware, and can be used in a program.

=== OPTION CYW43 PINS wl_on, wl_d, wl_cs, wl_clk
or
OPTION CYW43 PINS DEFAULT
--- P roomy
__RP2350 WIFI AND BLUETOOTH VERSIONS ONLY __Specifies the pins used to connect to the wireless chip, for modules that do not connect it in the same way as the Raspberry Pi Pico 2 W (GP23, GP24, GP25 and GP29).  ‘wl_on’ is the chip’s power-on pin, ‘wl_d’ its data pin, ‘wl_cs’ its chip select and ‘wl_clk’ its clock.  For example, the Waveshare RP2350B Pico WiFi board needs OPTION CYW43 PINS GP36, GP37, GP38, GP39.  DEFAULT returns to the standard pins.
The pins must be unused.  ‘wl_d’ and ‘wl_clk’ must both be within GP0 to GP31 or both within GP16 to GP47.  If an I2S DAC is configured it shares a PIO with the wireless chip, so its pins must be within the same range.
The configured pins are reserved and cannot be used by a program.  If the wireless chip does not respond on them the firmware reports this when it starts and runs without WiFi or Bluetooth.  OPTION RESET also returns to the standard pins.
This command must be run at the command prompt (not in a program) and will cause a restart.

=== OPTION FAST AUDIO ON|OFF
--- roomy
When using the PLAY SOUND command, changes to sounds, volumes, or frequencies can cause audible clicks in the output. The firmware attempts to mitigate this by ramping the volume down on the channel’s previous output before changing the output and ramping it back up again. This significantly improves the audio output but at the expense of a short delay in the PLAY SOUND command (worst case 3mSec). This delay can be avoided using OPTION FAST AUDIO ON in a program. The audible clicks may then re-appear but this is at the programmer’s discretion. 
This is a temporary option that is reset to OFF whenever a program is run.

=== OPTION FNKey string$
--- P roomy
Define the string that will be generated when a function key is pressed at the command prompt.  ‘FNKey’ can be F1, and F5 thru to F9.  Setting string$ to "" erases the saved function and restores the original function of the key.
Example:
OPTION F8  “RUN “+chr$(34)+”myprog” +chr$(34)+chr$(13)+chr$(10). 
This command must be run at the command prompt (not in a program).

=== OPTION KEYBOARD nn [,capslock] [,numlock] [,repeatstart] [,repeatrate]
or
OPTION KEYBOARD DISABLE
--- P roomy
__PS2 KEYBOARD VERSIONS ONLY__ Configure a PS2 keyboard.  This can be used for console input and any characters typed will be available via any commands that read from the console.  ‘nn’ is a two character code defining the keyboard layout: US for the standard layout used in the USA, Australia and New Zealand, UK for the United Kingdom, FR for France, GR for Germany, IT for Italy, ES for Spain, BE for Belgium and BR for Brazil.  The optional parameters ‘capslock’ and ‘numlock’ are true/false integers that set the initial state of the keyboard (default is 0 and 1).  The optional parameters ‘repeatstart’ and ‘repeatrate’ set the time before a held key first repeats and the rate of subsequent repeats: ‘repeatstart’ is 0 to 3 indicating 250mSec, 500mSec, 750mSec and 1000mSec (default is 1) and ‘repeatrate’ is 0 to 31 indicating 33mSec to 500mSec as per the PS2 keyboard specification (default is 12 or 100mSec).  This command must be entered at the command line and will cause a reboot.  The setting can be removed with OPTION KEYBOARD DISABLE.

=== OPTION KEYBOARD nn [,capslock] [,numlock] [,repeatstart] [,repeatrate]
--- P roomy
__USB AND BLUETOOTH KEYBOARD VERSIONS ONLY__ Set the layout and the initial state of a USB or Bluetooth keyboard.  ‘nn’ is a two character code: US, UK, FR, GR, IT or ES.  BE and BR are not available on these versions.  The optional parameters ‘capslock’ and ‘numlock’ are true/false integers that set the state of Caps Lock and Num Lock when a USB keyboard is connected (default is 0 and 1); a Bluetooth keyboard always starts with both off.  A keyboard with a numeric keypad built into its letter keys, such as the Raspberry Pi keyboard, needs ‘numlock’ set to 0 or keys such as U, I and O will type 4, 5 and 6.  The optional parameters ‘repeatstart’ and ‘repeatrate’ set the time before a held key first repeats (100 to 2000mSec, default 600mSec) and the time between subsequent repeats (25 to 2000mSec, default 150mSec); if they are omitted the current setting is kept.  These can also be set with OPTION KEYBOARD REPEAT.  OPTION KEYBOARD DISABLE is not available.  This command must be entered at the command line and will cause a reboot.

=== OPTION LCD SPI clkpin, mosipin, misopin
or
OPTION LCD SPI DISABLE
--- P keep roomy
__RP2350 PICOMITE VERSIONS ONLY __The firmware supports separating out the SPI pins used to drive a LCD display from those used for touch and/or the SDcard. By keeping these separate, this allows the firmware to use the second processor to work with the display with no risk of impacting the other functions. Setting the LCD SPI pins is a pre-requisite for using buffered drivers with the RP2350 PicoMite. The pins specified must be valid SPI pins for the functions clk, mosi (tx), and miso (rx). Where SYSTEM SPI pins are also specified, these must be on a different SPI channel.
OPTION LCD SPI DISABLE releases the pins.

=== OPTION MODBUFF ENABLE/DISABLE [sizeinK]
--- P roomy
Creates or removes an area of flash memory used for loading and playing .MOD files. If enabled then a mod buffer is created with a size of 128Kbytes. This can be overridden with “sizeinK”.
Note that this option reserves part of the Flash Filesystem (ie, it shrinks the Flash Filesystem).  The default is disabled.
Note: This option is not required on an RP2350 with PSRAM enabled. In this case the MOD file will be loaded to space in the PSRAM.
Note: On an RP2350 with 16MB of flash the mod buffer is always present and fixed at 1Mbyte (it does not shrink the Flash Filesystem), and this option cannot be used.

By default, the firmware operates a USB mouse in boot mode.  This means it returns 8-bit x and y positions and the state of the standard 3-buttons.  By setting OPTION MOUSE SENSITIVITY the firmware will command the mouse to operate with its full capabilities.  This means that it will try and interpret the full USB report received from the mouse including the wheel position, all buttons and the full resolution x/y position information.  To do this the firmware reads the mouse's HID report descriptor when it is plugged in and decodes whatever report layout the mouse declares - any number of buttons, any width of x and y movement, padding in any position and reports which use report IDs.  If the mouse does not declare usable x and y movement, or will not leave boot mode, the firmware automatically falls back to the standard boot report. 
Setting ‘f$’ will enable the full mouse report and scale the x/y positions by ‘f!’
The firmware cannot support all types of mouse, so if this causes problems with a specific mouse reset back to boot mode by using OPTION MOUSE SENSITIVITY 0.
Enabling this option with a value of 1.0 using a standard Microsoft Basic Optical mouse has been fully tested and will enable the wheel to be used in a program

=== OPTION PIN nbr
{b=120} 
--- roomy
Set 'nbr' as the PIN (Personal Identification Number) for access to the console prompt.  'nbr' can be any non zero number of up to eight digits.
Whenever a running program tries to exit to the command prompt for whatever reason MMBasic will request this number before the prompt is presented.  This is a security feature as without access to the command prompt an intruder cannot list or change the program in memory or modify the operation of MMBasic in any way.  To disable this feature enter zero for the PIN number (i.e.  OPTION PIN 0).  
A permanent lock can be applied by using 99999999 for the PIN number.  If a permanent lock is applied or the PIN number is lost the only way to recover is to reload the PicoMite firmware.
This command must be run at the command prompt (not in a program).

=== {}
OPTION PROFILING ON
or
OPTION PROFILING OFF
or
OPTION PROFILING ON, SAMPLE [, entries]
--- P roomy
Enables or disables the execution profiler.  When enabled, counters record how often each statement executes and a [PERF] report listing the most executed commands and the busiest subroutines/functions is printed when the program ends.  Profiling has no overhead when disabled.
If the report shows that most of the time goes in a few subroutines or functions, the mmb2csub tool can convert them into CSUBs, which run many times faster (typically 10 to 35 times for loops and arithmetic).  See the separate manual mmb2csub.pdf.
The option must be in the program, as RUN turns profiling off, and the report is printed by END: not when a program runs off its last line or is stopped with CTRL-C.  The report also gives local_peak, the most local variables alive at once, of the number available.
OPTION PROFILING ON, SAMPLE also samples where the processor is about 10,000 times a second, and the report adds the program lines that took the most samples, as [PCSLINE] line samples (a line of -1 is in the library).  ‘entries’ sets the size of the sample tables, from 256 to 65536 (default 4096).
With OPTION COMPILE ON the statement count and the list of commands cover only the statements that ran on the interpreter, so the list shows exactly what was not compiled, busiest first.
See the separate manual option-profiling-cache.pdf for the details.

=== OPTION RADIO BOTH | WEB | BLUETOOTH | NONE
--- P roomy
__PICOMITEPC3 ONLY __Selects which halves of the wireless chip the next boot brings up.
BOTH (the default) starts the WiFi and the Bluetooth host.  WEB leaves the Bluetooth host out: no Bluetooth stack, no firmware download and no polling, so the BLUETOOTH commands and OPTION AUDIO BLUETOOTH refuse.  BLUETOOTH leaves the WiFi down: no network join and no TCP, TFTP or UDP servers, and the WEB commands refuse.  NONE leaves the chip unpowered and unused, its four pins are free for general use and the heartbeat LED is on GP25.
The stored WiFi network and the Bluetooth pairings are kept, so a setting can be changed back at any time.  The Bluetooth host cannot be switched off while the audio is on Bluetooth (OPTION AUDIO).  The setting is saved and the firmware restarts.
eg. OPTION RADIO WEB

=== OPTION SYMBOLS OFF
--- roomy
Placing this command at the start of a program will cause it to run without the symbol tables that MMBasic normally builds when a program is run.  These tables speed up access to variables, subroutines and functions but they use some memory (typically 3KB to 5KB) and a large program written for an earlier version of MMBasic may need that memory.  If such a program runs out of memory the error message will suggest this option.
It must be on a line by itself before any other command except for comment lines and a LIBRARY LOAD command (which can come before or after it).  It cannot be used at the command prompt.

=== OPTION SYSTEM I2C sdapin, sclpin [,SLOW/FAST]
