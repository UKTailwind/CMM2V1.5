# The Commodore 64 Emulator

This is frank-c64, rh1tech's port of Christian Bauer's Frodo emulator. It is a PAL Commodore 64 with a 1541 disk drive, and runs at the C64's 50 frames a second with most of the processor to spare, in MODE 7.

It runs on the Generation 1 and the Generation 2.

## Starting It

```
CHDIR "A:/c64"
RUN "c64.app"
```

A start screen shows for five seconds, and then the C64's BASIC is ready. The C64's ROMs are built into the program.

The program calls the folder it was started in /c64.

## Loading Programs

Put disk images (.d64, .g64, .d81), programs (.prg) and cartridges (.crt) in A:/c64, and press **F10**. Choose one with the arrows and Enter, and then:

- **Load (Run)** runs a program or a cartridge. For a disk, it puts the disk in drive 8 and loads the first program on it, with LOAD"*",8,1: type RUN when READY. appears.
- **Mount (Insert)** puts a disk in drive 8 and goes back to BASIC, so that you can type LOAD"$",8 and LIST to see what is on it, then LOAD"NAME",8 and RUN.

Esc goes back a step. Folders inside A:/c64 are listed too, and Enter opens one.

Saving to a disk image, and cartridges, have not been tried yet.

Tapes (.tap, .t64) are listed, but cannot be loaded.

## The Keys

{widths: 16,36}
| Keys | What they do |
| F1 to F8 | The C64's F1 to F8 (its F2, F4, F6 and F8 are Shift with F1, F3, F5 and F7) |
| F9 | Swaps the joystick ports |
| F10 | Disks, programs and cartridges |
| F11 | RESTORE |
| Ctrl+Alt+Del | Reset the C64 |
| Ctrl+Alt+End | Back to MMBasic |
| Esc | RUN/STOP |
| Left Ctrl, Tab | CTRL |
| Left Alt | The Commodore key |
| Home | CLR/HOME |
| Insert | INST |
| Backspace, Delete | DEL |
| Caps Lock | SHIFT LOCK |
| The arrows | The cursor keys |

The other keys give what is printed on them, following OPTION USBKEYBOARD, so the symbols are where your keyboard has them. Shift with a letter gives the C64's graphics characters, as on a real C64, or its capitals once Shift and the Commodore key have switched it to lower case. The C64 has keys of its own for some characters: ^ gives its up arrow, _ its left arrow, and \ or £ its pound sign.

Ctrl-C is a C64 key here, so it does not end the program.

## Joysticks and the Mouse

The first USB gamepad is joystick port 2, where most games look, and the second is port 1. **F9** swaps them. The d-pad or the left stick steers, and any of the four face buttons fires. A DualShock 3 sends nothing until its PS button has been pressed.

The arrow keys are joystick port 2 as well, with the right Ctrl or right Alt as its fire button.

A mouse is a Commodore 1351 mouse in port 1, for GEOS and the other programs written for one. Its left button is the fire button, and its right button is up.
