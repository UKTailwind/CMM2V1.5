# The TRS-80 Emulator

This is the Tandy Radio Shack TRS-80: the Model I, the Model III, the Model 4 and the Model 4P. It is sdltrs, Mark Grebe's and Jens Guenther's emulator, which grew from Tim Mann's xtrs, made to run on the Colour Maximite 2. It has floppy and hard disks, cassettes, sound, the hi-res graphics boards, a joystick, a mouse and a serial port, and its own menu for all of them.

It runs at the TRS-80's own speed with most of the processor to spare. The Model 4's screen of 80 columns and 24 lines fills MODE 8 exactly; the 64 by 16 screen of the Models I and III is shown in the middle of it.

It is for the Generation 1 and the Generation 2. One expansion, the MegaMem memory board, works on a Generation 2 only. It needs firmware 7.00.00RC3 or later, and has been tried with 7.00.00RC5.

## What You Need

No Tandy ROM comes with the emulator, as they are still copyright. What you need depends on the model:

{widths: 12,40}
| Model | What it needs |
| Model 4P | Nothing but a Model 4 system disk. The emulator has a free boot ROM built in (Peter Cervasio's), which starts a Model 4 disk such as LS-DOS 6.3.1 |
| Model I | The Level II BASIC ROM, as a file named level2.rom |
| Model III and Model 4 | The Model III ROM, as a file named model3.rom |
| Model 4P, with its own ROM | Optional: model4p.rom. With it the 4P can start Model III disks as well |

Put the ROM files in A:/trs80 with the program. If you have a TRS-80, its ROMs can be read out with the usual tools; other TRS-80 emulators use the same files.

**System disks.** LDOS 5.3.1 (for the Models I and III) and LS-DOS 6.3.1 (for the Models 4 and 4P) may be copied freely, by permission of their owner, and Tim Mann keeps them at www.tim-mann.org/trs80.html as ld1-531.dsk, ld3-531.dsk and ld4-631.dsk. Put them in A:/trs80.

So the quickest way to see it work, with nothing of Tandy's at all, is the Model 4P with LS-DOS:

```
CHDIR "A:/trs80"
RUN "trs80.app", -model 4p -disk0 ld4-631.dsk
```

## Starting It

```
CHDIR "A:/trs80"
RUN "trs80.app"
```

With nothing after the name it starts the Model I if level2.rom is there, otherwise the Model III if model3.rom is there, otherwise the Model 4P. With no disk in the first drive, a Model I, III or 4 goes straight to its ROM BASIC and its READY prompt.

Words after a comma choose the rest. These are the ones most used; sdltrs has many more, and all of them work here:

{widths: 18,34}
| Words | What they do |
| -model 1, -model 3, -model 4, -model 4p | The model |
| -disk0 file to -disk7 file | That disk image in a drive at the start. The TRS-80 starts from the disk in drive 0 |
| -cassette file | That cassette |
| name.cmd | A TRS-80 machine language program (a /CMD file) loaded and run as soon as the TRS-80 has started |
| -himem 32000 | BASIC is given the memory up to that address only, leaving the rest for machine code (see below) |
| -ask | The TRS-80's questions as it starts are left for you to answer |
| -megamem | The MegaMem memory board (Generation 2 only) |
| -serial COM1 | The TRS-80's RS-232 port on a serial port of the Colour Maximite 2: COM1, COM2, or COM4 to COM7 for a USB serial device |
| -fdc, -nofdc | The disk controller always there, or never (see below) |

The settings are kept in the file sdltrs.t8c in the folder, which the emulator makes the first time. Its menu can change and save them.

### The Questions a TRS-80 Asks

A real TRS-80 asks questions each time it starts, and the emulator answers them for you:

- **MEMORY SIZE?** (and **Cass?** on a Model III or 4) from the ROM. The answer given is Enter, which gives BASIC all the memory, and the screen is then cleared. -himem gives a different answer, for a program that needs memory kept free above BASIC.
- **Date** and **Time** from a disk operating system. A TRS-80 has no clock that keeps the time, so LDOS and the others ask. They are answered from the Colour Maximite 2's clock. LS-DOS 6.3.1 knows no year after 2011, so it is given the year 28 years earlier, whose calendar is the same day for day: 2026 is entered as 1998, and the day of the week is right.

With -ask, nothing is answered and the TRS-80 starts exactly as a real one does.

### With No Disk in the Drive

A real Model I with a disk drive and no disk in it shows a blank screen for ever, waiting for the disk. So that this does not happen, the emulator takes the disk controller away whenever the first drive is empty at a reset, and the TRS-80 goes to its ROM BASIC. Put a disk in from the menu, press F10 to reset, and the TRS-80 starts from it. -fdc keeps the controller there whatever is in the drive, as on the real machine.

## The Menu

**F7** opens sdltrs's menu, over the TRS-80's screen. The arrows move, Enter chooses, and Esc or F7 goes back.

{widths: 20,32}
| Entry | What it is for |
| Floppy Disk Management | Putting disk images in the eight drives and taking them out, making a blank disk, and saving a set of disks to load together later |
| Hard Disk Management | Hard disk images |
| Cassette/Tape Management | Choosing a cassette file, and where on the tape it is |
| Emulator Settings | The model, the speed, the memory expansions, the graphics board |
| Display Settings | Colours, the character set, the drive lights |
| Miscellaneous/Printer | Sound, the keyboard, the printer's file, the serial port |
| Configuration/State Files | Saving and loading the settings, and the whole state of the TRS-80 |
| Joystick Settings | Giving gamepad buttons a key or a menu each, and a test of the buttons |
| ROM File Selection | Other names for the ROM files |
| TRS-80 Power Reset | Off and on again |

In the list of files, Enter opens a folder or chooses a file.

Disk images in the usual formats work: JV1, JV3 and DMK (.dsk, .dmk, .jv1, .jv3). What the TRS-80 writes to a disk goes into its file on the card, so your programs and files last.

A disk cannot be write-protected from the menu on the Colour Maximite 2.

## The Keys

{widths: 18,34}
| Keys | What they do |
| F7 | The menu. Shift+F7: the emulator's settings |
| F8 | Leaves, after asking. Shift+F8, or Ctrl+Alt+End: leaves at once |
| F10 | Reset. Shift+F10: a reset as from switching on |
| F11 | Shows sdltrs's keys on the screen |
| F12 | Turbo: full speed, until pressed again |
| Pause | Stops the TRS-80 until pressed again |
| Esc | BREAK |
| Home, Delete | CLEAR |
| Backspace, left arrow | The left arrow |
| Tab, right arrow | The right arrow |
| Up and down arrows | The up arrow (^ in BASIC) and the down arrow |
| End | Shift and the down arrow, which some programs use as a Control key |
| Left Ctrl | The Model 4's CTRL |
| F1, F2, F3 | The Model 4's F1, F2 and F3 |
| F4, Caps Lock | The Model 4's CAPS |
| F5, Scroll Lock | The @ key |
| Alt+D, Alt+T, Alt+H | The menu's pages for disks, cassettes and hard disks |
| Alt+B | Shows the drive lights under the picture. The Model 4's screen with them is taller than MODE 8, so the display changes to MODE 1 |

The other keys give what is printed on them, following OPTION USBKEYBOARD.

**Capitals.** A Model I types capitals without Shift, and Level II BASIC shows nothing else. With a disk operating system such as LDOS, Shift with a letter gives lower case, and Shift+0 swaps the two. It has no Caps Lock key, so Caps Lock does nothing on it. This is the Model I itself, not a fault. The Models III and 4 start in capitals too, and Shift+0 or the CAPS key changes that.

Ctrl-C is a TRS-80 key here, so it does not end the program.

## Joystick and Mouse

The first USB gamepad is the TRS-80's joystick, the Alpha Products one that most games know. The d-pad or either stick moves it, and a face button fires. In the menu the d-pad moves about. The numeric keypad is the joystick as well: 8, 2, 4 and 6 the directions, and 0 or 5 the fire button.

The menu's Joystick Settings can give any button a key or a page of the menu. Its test shows buttons only, not the d-pad or the sticks.

The mouse's right button opens the menu, where the left button chooses and the right goes back. The Model 4's mouse driver, for programs that use a mouse, is on sdltrs's utility disk.

A DualShock 3 sends nothing until its PS button has been pressed.

## Sound

Sound through the cassette port, which is how nearly all TRS-80 games make it, comes out of the Colour Maximite 2's audio output, as do the Model 4's sound port and the Orchestra 85 and 90 music boards.

## What Has Been Tried

On both the Generation 1 and the Generation 2: Level II BASIC on the Model I; Model III BASIC; LDOS 5.3.1 from disk on the Models I and III; LS-DOS 6.3.1 on the Model 4 and on the Model 4P with the free boot ROM; the menu and its disk list; sound through the cassette port; the USB keyboard, the mouse's buttons and wheel, and a gamepad's d-pad, sticks and buttons. Saving a BASIC program to a disk and loading it again after leaving has been tried on a Generation 1.

Not yet tried on the Colour Maximite 2: cassette files, /CMD files, hard disks, the hi-res graphics boards, the printer, the serial port, saved states, and games with a joystick.

## Differences from sdltrs on a PC

- The picture is always at its natural size: there is no scaling.
- The MegaMem works on a Generation 2 only. The other memory expansions (SuperMem, HyperMem and the rest) work on both.
- The clipboard, the debugger and write protection from the menu are not there.
- A saved state can be loaded only on the generation of Colour Maximite 2 that saved it.

## Leaving

F8 asks first; Shift+F8 or Ctrl+Alt+End leaves at once. The menu's Quit SDLTRS does too.
