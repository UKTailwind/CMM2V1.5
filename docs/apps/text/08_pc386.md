# The 386 PC

pc386 is tiny386, Chunhui He's 386 PC emulator, with a VGA card, a Sound Blaster 16, an Adlib and the PC speaker. The Colour Maximite 2's keyboard and mouse are the PC's. It runs FreeDOS, MS-DOS, Windows 3.1 and Windows 95.

This chapter gets you started. Everything else, including installing MS-DOS and Windows, is in its own manual, *Colour Maximite 2 386 PC Emulator*, posted with the firmware.

## Starting It

```
CHDIR "A:/pc386"
RUN "pc386.app"
```

The screen changes to 640 x 480, and FreeDOS 1.3 starts from a 32 MB hard disk image. It loads its mouse driver and ends at the C:\> prompt.

A PC is described by a configuration file. The one used unless you say otherwise is pc386.ini. To start a different PC, name its file:

```
RUN "pc386.app", msdos.ini
```

msdos.ini installs MS-DOS 6.2 from images of your own Setup disks, and msdosc.ini then starts it, with Windows 3.1's disks to hand.

## Leaving It

Press **Ctrl+Alt+End**. This switches the PC off at once, as if its power had been cut, so first:

- Finish what the PC is doing, and leave Windows if it is running.
- Wait until the PC has stopped writing to its disks.

The PC's disks are image files on the SD card, so everything written to them is kept for the next time.

## The Keys

Three keys, held with Ctrl and Alt, are the emulator's own. Every other key goes to the PC, Ctrl+Alt+Delete included: it restarts the PC. Ctrl-C goes to the PC as well, and does not stop the emulator.

{widths: 18,34}
| Keys | What they do |
| Ctrl+Alt+End | Leave the emulator |
| Ctrl+Alt+Page Down | Put the next floppy image of the list in drive A: |
| Ctrl+Alt+Page Up | Put the previous floppy image in drive A: |

The keypad's 1, 3 and 9 work too, if a keyboard does not report those combinations.

DOS uses a US keyboard layout unless you load another. For a UK keyboard, put this in AUTOEXEC.BAT:

```
KEYB UK
```

## The Mouse and Sound

DOS programs need a mouse driver. The FreeDOS disk loads CuteMouse, and Windows 3.1 has its own.

Sound comes out of the Colour Maximite 2's audio output. DOS programs find the Sound Blaster at port 220, IRQ 5, DMA 1 (high DMA 5), and an Adlib at port 388. Many of them read these settings from the BLASTER variable, which AUTOEXEC.BAT can set:

```
SET BLASTER=A220 I5 D1 H5 T6
```

## Making It Faster

- OPTION SD TIMING FAST makes the SD card, and so the PC's disks, much faster.
- On an original Colour Maximite 2 whose processor is of revision Y, OPTION OVERCLOCK ON makes it as fast as on a Generation 2.

## Moving a PC

A PC is a few files in a folder, so copying them moves it to another Colour Maximite 2 of either generation. FreeDOS can be passed on to other people. MS-DOS, Windows and other commercial programs cannot.
